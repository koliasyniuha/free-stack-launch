How it works

CLI first. Browser only when it must.

Steps with a CLI or API run there, so they are repeatable. Dashboards with no CLI open in your Chrome, with your permission, while you watch.

01

Reads your repo

Language, framework, the env vars it expects, and whether there is a mobile client.

02

Sets up each service

Creates projects and least-privilege tokens, and puts every key straight into your secrets manager.

03

Deploys and checks

Ships the server, runs a health check, wires up alerts, and adds budget alerts where a card is on file.

Questions

Something else? Open an issue on GitHub.

Is it really free?

The plugin is free and MIT-licensed. Every service it sets up has a free tier. The plugin never charges you. If you publish a mobile app, Apple and Google charge their own store fees, as they do for every developer: $99 per year for the App Store and $25 once for Google Play. You pay them directly. Some providers, such as Cloud Run and R2, ask for a card, and the plugin sets budget alerts there.

Does it need my passwords or card details?

No. You create the accounts and sign in yourself. Tokens go straight into your secrets manager from the terminal, never into chat.

Which apps does it work with?

Any app with a backend that fits in a container, such as Node, Python or Go servers. For mobile it supports Expo / React Native, Flutter and native Swift or Kotlin apps.

What happens when I outgrow the free tiers?

Check STACK.md in your repo. It lists each free limit, the sign that it is time to upgrade, and the next plan with its price.

How do I install it?

In Claude Code, run claude plugin marketplace add koliasyniuha/free-stack-launch, then claude plugin install free-stack-launch@free-stack-launch. In Codex or Cursor, copy the skill folder into ~/.agents/skills/ (pick the "Codex · Cursor" tab above) and restart the agent. Then tell your agent: "deploy a free stack for my app".

Does it work with Codex or Cursor?

Yes. The skill uses the open Agent Skills format (SKILL.md), which Codex, Cursor and many other agents read. Browser steps use your agent's own browser tool. If it has none, the skill gives you the link for each step and says what to click.
