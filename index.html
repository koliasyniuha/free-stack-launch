Free Stack Launch

A Claude Code plugin that takes an app working on your machine (often vibe-coded) and puts it into production on free tiers. If the app has a mobile client, it also helps you publish it to the App Store and Google Play.

View on GitHub

Install

claude plugin marketplace add koliasyniuha/free-stack-launch
claude plugin install free-stack-launch@free-stack-launch

Then, in your project, tell Claude Code: "deploy a free stack for my app".

Optional: a staging environment. At the end it writes a STACK.md in your repo: what lives where, each free limit, and the sign that it is time to upgrade.

App Store and Google Play

For Expo / React Native, Flutter or native apps, it walks you through store console setup, builds and the review steps. Costs that are not free: Apple Developer Program ($99/year) and Google Play Console ($25 one-time).

What stays with you

  • Creating accounts, logins, payments, legal agreements and ID checks.
  • Approving every step that costs money or cannot be undone.
  • Entering tokens in the terminal, never in chat.

Privacy

The plugin has no server of its own and stores no data. API keys go straight into your secrets manager. Read the privacy section.
